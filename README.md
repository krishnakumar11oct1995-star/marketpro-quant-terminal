# MarketPro Quant Terminal & Multi-Agent Suite

> Desktop financial analysis workstation and algorithmic trading research system built with PyQt6.

## 🚀 Features
- **Dockable Terminal UI:** Professional multi-panel dashboard with Watchlists, Screener, Stock Detail, Options, and Portfolio Tracker.
- **Quantitative Research Agents:** Markowitz mean-variance efficient frontier optimization and automated strategy backtesting.
- **Interactive Charting:** Fast pyqtgraph candlestick rendering with technical indicators (SMA, EMA, RSI, MACD, Bollinger Bands).
- **Dark Theme Interface:** Clean, high-performance desktop UX.

## 🛠️ Tech Stack
- Python 3.10+
- PyQt6 & pyqtgraph
- yfinance, Pandas, NumPy
- PyPortfolioOpt & QuantStats
